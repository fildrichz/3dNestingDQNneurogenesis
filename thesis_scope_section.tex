\section{Scope of This Work}

This work combines evolutionary neural architecture search with deep reinforcement learning for the 3D bin packing problem. We aim to demonstrate that genetic algorithms can automatically discover neural network architectures suited to constraint-specific packing scenarios without manual hyperparameter tuning.

\subsection{Problem Scope}

We address offline 3D bin packing where all items are known in advance. Items are rectangular boxes with axis-aligned orientations, and bins are identical containers. The system must satisfy realistic shipping constraints:
\begin{itemize}
    \item \textbf{Weight capacity}: per-bin maximum weight limits
    \item \textbf{Incompatibility}: certain item pairs cannot share bins
    \item \textbf{Affinity}: certain items must be packed together
    \item \textbf{Relative positioning}: heavy items cannot rest on lighter items
    \item \textbf{Center of mass}: stability constraints on load distribution
\end{itemize}

We do \emph{not} address online/dynamic packing (items arriving in real-time), vehicle routing integration, non-convex items, arbitrary 3D rotations, or fragility hierarchies beyond weight-based rules.

\subsection{Technical Approach}

The system integrates three key components:

\paragraph{Placement Candidate Generation.}
Empty Maximal Spaces (EMS) heuristic generates geometrically feasible placement positions. Heightmap tracking (2D grid of maximum heights) enables efficient gravity simulation and spatial feature extraction.

\paragraph{Neural Scoring Model.}
A deep Q-network evaluates candidate placements using:
\begin{itemize}
    \item Convolutional spatial feature extraction from local heightmap patches
    \item Multi-layer perceptron encoders for state and action features
    \item Attention mechanisms (standard Transformer or Set Transformer) to model relationships between candidate actions
    \item Q-value prediction for reinforcement learning
\end{itemize}

The architecture (layer depth, hidden dimensions, attention type, activation functions, dropout) is determined by evolutionary search rather than manual design.

\paragraph{Genetic Architecture Search.}
A genetic algorithm evolves neural network architectures by encoding 11 parameters as genes (network depth, width, attention configuration, regularization). Tournament selection, uniform crossover, and multiplicative mutation operate over multiple generations. Fitness combines packing utilization, bin count, and model complexity.

\subsection{Evaluation Strategy}

We evaluate on benchmark datasets (3dBPP, thpack, BR instances with 38--100 items per problem). The goal is to demonstrate that:
\begin{enumerate}
    \item Evolved architectures outperform random architectural choices
    \item The system can learn effective placement strategies under multiple constraint types
    \item Genetic search discovers problem-appropriate inductive biases (e.g., convolutional spatial reasoning, attention over actions)
\end{enumerate}

This is a research prototype demonstrating feasibility, not a production system. We do not claim state-of-the-art performance against mature classical heuristics, nor do we provide exhaustive statistical validation with confidence intervals or systematic ablation studies. The focus is on establishing that neurogenesis can automate architecture design for constraint-aware bin packing.
