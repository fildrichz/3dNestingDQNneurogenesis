# Architecture Evolution Plots - Explanation

This document explains the visualization elements in the "Architecture Evolution" plots generated during genetic algorithm experiments.

## Overview

The Architecture Evolution figure contains 4 subplots that track how neural network architectures evolve across generations during the genetic algorithm optimization process. The plots are generated by the `plot_architecture_evolution()` function in `main/ga_evolution.py:1056`.

## Plot 1: Network Complexity Evolution (Top-Left)

**What it shows:**
- Tracks the average network complexity (in millions of parameters) across all genomes in the population over generations

**Visual elements:**
- **Magenta line with circles**: Average complexity at each generation
- **Shaded purple area**: Standard deviation band (mean ± 1 std)
  - Shows the spread/diversity of complexities in the population
  - Wider band = more diversity in network sizes
  - Narrower band = population converging to similar architectures

**What to look for:**
- **Decreasing trend**: Natural selection favoring simpler, more efficient architectures
- **Increasing trend**: Evolution finding that larger networks perform better
- **Stabilization**: Population converging to optimal complexity
- **High variance early, low variance late**: Typical healthy evolution pattern

**Code reference:** `ga_evolution.py:1079-1090`

## Plot 2: Hidden Dimension Distribution (Top-Right)

**What it shows:**
- Distribution of `hidden_dim` gene values across the population at sampled generations
- Sampled every ~10% of total generations to show evolution over time

**Visual elements (box plot components):**
- **Orange horizontal line**: Median hidden dimension in the population
- **Box**: Interquartile range (IQR) - middle 50% of values
  - Bottom edge: 25th percentile (Q1)
  - Top edge: 75th percentile (Q3)
- **Vertical lines (whiskers)**: Extend to most extreme values within 1.5×IQR
- **Circles**: Outliers beyond whiskers (extremely large/small hidden dimensions)

**What to look for:**
- **Shrinking boxes**: Population converging on optimal hidden dimension
- **Median movement**: Evolution favoring larger or smaller hidden dimensions
- **Outliers persisting**: Some genomes exploring extreme architectures
- **Multiple clusters**: Population maintaining diversity in hidden dimensions

**Code reference:** `ga_evolution.py:1092-1109`

## Plot 3: Encoder Layers Distribution (Bottom-Left)

**What it shows:**
- Distribution of `enc_layers` gene values (number of encoder layers) across sampled generations
- Same sampling strategy as hidden dimensions plot

**Visual elements (box plot components):**
- Same as Hidden Dimension plot but for layer count
- **Orange line**: Median number of encoder layers
- **Box**: Middle 50% of layer counts
- **Whiskers**: Range of typical layer counts
- **Circles**: Outlier architectures with unusual layer counts

**What to look for:**
- **Convergence to specific layer count**: Evolution finding optimal depth
- **Preference for shallow vs deep**: Median moving toward lower/higher values
- **Integer values**: Layer counts are discrete (1, 2, 3, 4, etc.)
- **Vanishing outliers**: Population stabilizing on proven architectures

**Code reference:** `ga_evolution.py:1111-1128`

## Plot 4: Attention Types (Final Gen) (Bottom-Right)

**What it shows:**
- Bar chart of attention mechanism types that survived to the final generation
- Counts how many genomes in the final population use each attention type

**Visual elements:**
- **Sky blue bars**: Count of genomes using each attention type
- **X-axis labels**: Attention type names (e.g., 'none', 'standard', etc.)
- **Bar height**: Number of genomes with that attention type

**Possible attention types:**
- `'none'`: No attention mechanism (simplest)
- `'standard'`: Standard multi-head attention
- Other types defined in the genome

**What to look for:**
- **Dominant type**: Tallest bar shows which attention mechanism won natural selection
- **Diversity**: Multiple bars indicate population hasn't fully converged
- **Complete convergence**: Single bar means all genomes use same attention type
- **No 'standard' attention**: Simpler architectures performing better

**Code reference:** `ga_evolution.py:1130-1147`

## Interpretation Guide

### Healthy Evolution Patterns:
1. **Early generations**: High diversity (wide boxes, multiple attention types)
2. **Mid generations**: Gradual convergence (narrowing distributions)
3. **Late generations**: Stabilization around optimal values
4. **Complexity**: Often decreases as evolution finds efficient solutions

### Warning Signs:
1. **No convergence**: Distributions stay wide - may need more generations
2. **Premature convergence**: All diversity lost by generation 5-10 - population too small or mutation rate too low
3. **Oscillating complexity**: May indicate fitness function issues
4. **All outliers**: Box plots dominated by outliers - unstable evolution

## Data Sources

The plots are generated from:
- `evolution_history.json`: Contains averaged metrics per generation
- `generation_XXX.json`: Full population snapshots with individual genome genes
- Sampling strategy: ~10 snapshots evenly distributed across all generations
